# G3 0.4 核心修正與 demo 留言同步

## 來源與範圍

本版接續 `g3-platform-review` 的 `19b29be48c36151ea2b0fe246baf499fec1d957b`（線上 build.json 已核對）。依 11 月 4 日會議摘要、審閱 JSON 及用戶批註 PDF 修正第一批核心規則；沒有修改 IBKR 費率／收費演算法。留言登入及同步為獨立模組，不讀取行情或模擬結果。

## 已實作核心規則

- 新預設：股價平均 US$200–10,000、每檔目標 US$10,000、next-open、RR 相等通過；現有瀏覽器草稿保留，使用還原預設可套用新值。
- 波幅用每日開市價作分母，優先官方 daily.open；缺時明確用首根正常時段分鐘 open。兩者皆缺則無法篩選，絕不借用未來價格。
- 事件必須嚴格超過門檻；精度仍為 0.0001 美元。同一分鐘最多一次持倉決策。
- 個股預設 B/(R+1)；組合 ΣB/(ΣR+1)，整個分母只加一次。比較沿用精確交叉相乘。
- 排名邊界完全同分全納；代號只控制顯示排序。可能多於 N 隻，且不因同分重新攤薄每股目標。
- 入市、反手新方向按含滑價的模擬成交價重算整數股數；平舊倉用原持倉數量；同向持倉不持續再平衡。
- 缺前日整段分鐘者不進排名；缺當日整段分鐘者只剔除、不補選。Gate 的前日／當日均採同一剩餘股票名單；保留 selected 並另記 excludedPrevious、excludedCurrent、comparisonSymbols。此為一致比較的明確實作口徑，仍可另行研究不同名單政策。
- 新舊版本結果可並存，沒有把舊結果重算後冒充原結果。

## Demo 介面

姓名只作未驗證署名。所有已登入的人共享團隊記錄，可選擇、讀取及修改同一記錄；不是私人帳戶。每份記錄有獨立隨機 ID、修改者、伺服器時間及遞增 revision；同名建立不同記錄不會互相覆蓋。

登入不會自動搬移本機資料。使用者必須選擇載入現有記錄，或明確按「將本機留言另存為新團隊記錄」。遇 409 衝突時保留本機草稿，另存新記錄或匯出，再讀取團隊最新版本；不提供隱藏的強制覆蓋。JSON 匯出／匯入保持原有格式；額外提供只含留言的未同步備份匯出。

只保護留言 API；GitHub Pages 的 review.html / simulator.html、公開原始碼仍可讀。完整網站登入牆不在此方案內。

實際線上啟用條件及後端部署見 [demo 後端設定](../services/review-api/README.md)。未配置 API URL 時明確顯示未啟用，不能宣稱已跨瀏覽器同步。
