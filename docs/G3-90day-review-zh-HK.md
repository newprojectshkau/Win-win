# 90 個交易日的資料及模擬

更新：2026-10-31（Australia/Melbourne）。

這次直接擴展私人歷史資料包，並非只放寬日期輸入框。50 個已存檔代號的新包可選 **2026-06-23 至 2026-10-28，共 90 個交易日**，另含每次篩選需要的 20 個前置交易日。它與舊 30 日包及 AAPL 長期包分開保存。

## 如何開始

1. 使用對話提供的新版私人資料連結；公開文件不包含解密密鑰。
2. 選「50 個代號研究池／90 個交易日」，按「直接載入模擬器」。
3. 載入後，開始日期預設為 2026-06-23，結束日期為 2026-10-28，並自動執行 90 日。
4. 此瀏覽器會保存新資料。資料選單先顯示可測日數及日期，方便切換 90 日或舊 30 日。

若畫面仍顯示 30 日，代表目前仍使用舊資料包；「選取全部可測日期」只會選該包已有的日期，不會自動下載另一包。新版私人入口使用更新網址，避免瀏覽器快取舊版 30 日預設。

## 資料範圍及限制

- 每天仍從固定存檔研究池重新篩選；並非完整歷史 IB 可交易股票池。上市／退市、公司行動及點時可交易資格仍需進一步核對。
- 早期歷史市值另作補取，優先處理有大市值觀測、但相關回看窗口仍無法判定的存檔股票。這不是完整每日市值下載。
- 市值不足時，沿用「已知市值總和 ÷ 完整回看日數」作非負下限；下限嚴格超過門檻才可確認通過，否則列為不能判定。不把較新市值向過去填補。
- 分鐘缺漏不補價。無法完整建立前日排名或已選股票當日缺分鐘時，依現有政策阻擋整段。90 日表示測試日期窗口，不代表每隻股票每天資料完整，或每天都有成交。
- 所有數字仍屬固定成本及成交假設下的研究結果，未接實盤。現有每日損益柱、累計線、多指標圖及參數比較均可使用這 90 日窗口。

## 重現

```sh
python3 scripts/marketdata/prepare_expanded_scope.py --trading-days 90 --end 2026-10-28 --fetch-cap-samples
python3 scripts/marketdata/build_expanded_dataset.py --trading-days 90
node scripts/marketdata/run_window_replay.mjs /workspace/private/market-data/expanded-90days.dataset.json /workspace/private/market-data/expanded-90days.results.json 2026-06-23 2026-10-28
```

所有明文行情、範圍檔及結果存於 repo 外私人目錄。GitHub Pages 只載有加密資料；來源壓縮檔經 SHA-256 校驗後才使用。歷史市值／股數／同日股價的核對屬同供應商內部一致性檢查，不等同獨立價格或公布時間驗證。

## 90 日預設模擬結果及驗證

- 測試期：2026-06-23 至 2026-10-28，共 90 個交易日；52 日有成交。
- 成本後淨損益：−US$5,564.08；成本前 −US$12.23，佣金 US$3,692，模擬滑價 US$1,859.85。
- 3,692 筆成交，28 個不同代號；雙邊成交額 US$3,719,717.03。
- 每日合資格 23–28 股；2,129 個股票日因資料不足不能判定，13／180 個早午市時段被資料政策阻擋。
- 預設下一分鐘開市價成交、每筆 US$1 佣金、5 bps 滑價；成交量、買賣差價、借貨及排隊因素仍未完整模擬。
- 新包補取較早市值觀測，因此最近 30 日部分也未必與舊資料快照相同；舊包保留作重現。
- 343 組市值／加權股數與官方同日日線收市價的內部一致性檢查全部吻合；這並非外部來源驗證。
- 逐筆買賣現金流扣佣金與淨損益一致，每日結束持倉歸零。
- 驗證通過：30 項 Node 測試、6 項 Python 測試；瀏覽器實測加密載入、90 日預設、最早單日、全期按鈕、重開保存資料、90 根每日損益柱，結果與 Node 逐項一致。
